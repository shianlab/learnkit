# README 视觉素材

这组横幅与主题插画于 2026-10-09 使用 Codex 内置 imagegen 工具生成。视觉参考来自应用现有的米白、陶土橙和浅鼠尾草绿配色，以及书本图标。它们用于表达听读、笔记与复习的概念，不是应用截图。

| 文件 | 用途 |
| --- | --- |
| `readme-banner.jpg` | 四种语言 README 的顶部横幅 |
| `listen-read.jpg` | 听读学习主题插图 |
| `notes-review.jpg` | 笔记与复习主题插图 |
| `overview.png` | 原有真实应用截图，使用自制演示资料 |

生成的 PNG 原图保留在本地；仓库使用按比例缩小并压缩的 JPEG，以控制 README 加载体积。原有 `overview.png` 保持不变。
